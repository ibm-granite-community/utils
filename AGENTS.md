# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Build & Test Commands

- **Install dependencies**: `uv sync` (uses uv package manager, not pip)
- **Run all tests**: `uv run pytest`
- **Run single test**: `uv run pytest tests/test_notebook_utils.py::test_env_var_set`
- **Type checking**: `uv run pyrefly check` (uses pyrefly, not mypy)
- **Lint**: `uv run ruff check --fix`
- **Format**: `uv run ruff format`

## Non-Obvious Project Patterns

### Version Management

- Version is auto-generated by setuptools_scm from git tags into `src/ibm_granite_community/_version.py`
- This file is excluded from linting/type checking (see pyproject.toml lines 61, 68)

### Testing Conventions

- Tests use `assertpy` library, not standard assert statements (e.g., `assert_that(value).is_equal_to(expected)`)
- Test fixtures in `tests/conftest.py` are session-scoped for tokenizer (expensive to load)
- Tests that modify .env file must backup/restore it (see test_env_var_dotenv pattern)

### LangChain Integration Specifics

- `documents_chain.py` has special handling for ChatWatsonx model - wraps `chat_template_kwargs` in a `params` dict
- `TokenizerChatPromptTemplate` merges kwargs into input dict (lines 290, 311) - non-standard behavior
- `create_stuff_documents_chain` accepts a `document_mode: DocumentMode` parameter (enum) to control how documents are passed to the model:
  - `CHAT_TEMPLATE_KWARGS`: passes documents via `chat_template_kwargs` in the model invocation
  - `DOCUMENT_ROLES`: prepends `ChatMessage` objects with a `"document N"` role (use when the API does not support `chat_template_kwargs` but the model's chat template understands document role messages, e.g. older Granite models on Ollama)
  - `TOOL_CALL` (default): appends an `AIMessage` tool call and a `ToolMessage` with the documents serialized as XML (use when the API does not support `documents` parameter in `chat_template_kwargs` but the model supports tool calling)
- `add_tool_call_messages` in `utils.py` produces the AI tool call + ToolMessage pair; documents are serialized as `<documents><document id="…"><document_content>…</document_content></document>…</documents>` XML

### Code Style (Non-Standard)

- Line length: 180 chars (not 88/100 like most Python projects)
- Uses `# pyrefly: ignore` comments for type checker suppressions (not `# type: ignore`)
- SPDX license headers required on all source files

### Environment Variable Loading

- Multi-source priority: os.environ → Colab secrets → .env file → default → user prompt
- `find_dotenv(usecwd=True)` searches parent directories for .env (not just current dir)
- All loaded values are stored back to os.environ for consistency
